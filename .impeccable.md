# Design Context

### Users
Podcast creators and listeners using a mobile app for audio playback, episode management, and content discovery. Also includes admin users managing content via a web dashboard.

### Brand Personality
**Sleek & Premium** — Modern, polished interfaces with smooth animations, clean visual hierarchy, and a refined aesthetic that conveys quality and professionalism.

### Aesthetic Direction
- **Theme**: Dark mode first with light mode support, inspired by music/podcast apps (Spotify-style)
- **Visual approach**: Clean cards with subtle depth, smooth transitions, generous whitespace
- **Anti-references**: Avoid generic AI-generated aesthetics, cluttered interfaces, dated looks
- **Colors**: Neutral grays with a green accent (#00D2A0), high contrast text for readability

### Design Principles
1. **Refined minimalism**: Every element must serve a purpose; remove visual noise
2. **Smooth motion**: Meaningful animations that enhance, not distract
3. **Content-first**: Let podcast artwork and content take center stage
4. **Accessible by default**: Consider color blindness in palette selection, maintain WCAG contrast ratios
5. **Consistent rhythm**: Use the established spacing (4-48px) and radius (4-32px) scales consistently

### Tech Stack Context
- Mobile: Expo + React Native + React Native Paper (MD3)
- Admin: Next.js + Tailwind CSS
- Backend: NestJS + MongoDB
